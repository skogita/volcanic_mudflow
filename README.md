# volcanic_mudflow
Snow-melt volcanic mudflow (lahar) simulator — depth-averaged flow with erosion, snowmelt and heat — with a Windows window app (Japanese and English screens) — design docs and code from the book Toward a Million Lines XIV / 融雪型火山泥流のシミュレータと窓のアプリ（Windows・日英の画面）— 本『LLM で 100 万行のソフトウェア開発 XIV』の設計書とコード
